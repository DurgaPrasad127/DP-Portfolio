# Durga Prasad Portfolio

Vite-based version of the dark AI/ML portfolio.

## Requirements

- Node.js 18+ recommended
- npm

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Then open:

http://localhost:5173

## Production build

```bash
npm run build
npm run preview
```

## Structure

durga-prasad-portfolio/
├── package.json

├── src/
